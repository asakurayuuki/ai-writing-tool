# AIライティングツール

Gemini APIを使った個人用のオールインワン文章作成アシスタント（Streamlit製）。

## 機能

- 📝 ブログ記事作成
- ✉️ メール返信作成
- 📄 文章要約
- ✅ 校正・推敲
- 🔄 文体変換
- 💡 タイトル・見出し生成
- 🌐 翻訳
- 📱 SNS投稿文作成

## セットアップ

1. 依存パッケージをインストール

   ```
   pip install -r requirements.txt
   ```

2. Gemini APIキーを設定（どちらか一方でOK）

   - `.env.example` を `.env` にコピーし、`GEMINI_API_KEY` に自分のキーを設定する
   - もしくはアプリ起動後、サイドバーの「⚙️ 設定」から都度入力する（保存はされません）

   APIキーは https://aistudio.google.com/app/apikey から取得できます。

3. アプリを起動

   ```
   streamlit run app.py
   ```

## 注意

- 個人利用を前提としており、ログイン認証・データベースはありません。
- 入力した文章・生成結果はサーバーには保存されず、ブラウザのセッション内でのみ保持されます。
